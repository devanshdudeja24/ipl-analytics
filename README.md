# IPL Analytics and Win Predictor

A data analytics and machine learning project that analyzes IPL match trends and predicts a team's win probability, with an interactive Streamlit dashboard.

> **Note:** The dataset is simulated (generated by `generate_data.py`). Results are for demonstration and are not real IPL outcomes.

## Features
- Cleaned and analyzed 594 matches and 139K deliveries using pandas
- Toss and venue trend analysis using SQLite and Plotly
- Win-probability model using Logistic Regression and Random Forest
- Match-wise train/test split to prevent data leakage
- 3-tab Streamlit dashboard: team statistics, player statistics, live win predictor

## Tech Stack
Python, pandas, SQLite, Plotly, scikit-learn, Streamlit

## Model Results
| Model | Accuracy |
|---|---|
| Logistic Regression | 81.7% |
| Random Forest | 78.9% |

## Project Structure
- `raw/`: original generated data
- `processed/`: cleaned data
- `sql/`: SQL queries
- `notebooks/`: analysis and model training
- `models/`: saved trained models
- `app.py`: Streamlit dashboard
- `generate_data.py`: simulated data generator

## How to Run
1. Clone the repo:
   `git clone https://github.com/devanshdudeja24/ipl-analytics.git`
2. Install dependencies:
   `pip install -r requirements.txt`
3. Start the app:
   `streamlit run app.py`
